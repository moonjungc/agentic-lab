# src/payments/ 규칙

- **금액 단위**: 항상 전(minor unit, 1/100원) 정수. 예: `10,000원` = `1000000`.
- **로그**: `lib/logger.js`의 `logPayment(event, data, level)`만 사용한다. `console.log`/`logInfo`/`logError` 직접 호출 금지.
  - `data`는 `{ orderId, amountMinor, currency?, status }` 형태로 전달한다 (`currency` 생략 시 `'KRW'`).
  - 출력 JSON 필드: `ts`, `event`, `order_id`, `amount_minor`, `currency`, `status`.
- **테스트**: 이 폴더를 수정하면 반드시 `npm test`를 실행해 `tests/refund.test.js`가 통과하는지 확인한다.

전체 규칙은 루트의 @../../GOLDEN_RULES.md, 결제 세부 규칙은 @../../docs/payment-rules.md 참조.
